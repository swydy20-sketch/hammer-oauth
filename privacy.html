Privacy Policy — Hammer

Last updated: October 27, 2026

Hammer is a private, single-user automation tool. It is used only by its owner to access Google APIs through the owner's own Google Account. It is not a public service and has no other users.

1. What this app accesses

When you sign in, Hammer requests one Google scope:

  • https://www.googleapis.com/auth/generative-language.retriever — to send prompts to the Gemini API and receive responses, including Google Search grounding results.

2. How the data is used

Data is used only to perform the requests you explicitly start. Nothing is collected, profiled, or used for advertising.

3. Where the data is stored

OAuth tokens are stored locally on your own device, in a file named token.json. No data is sent anywhere except Google's own API endpoints.

4. Sharing

No data is shared, sold, or transferred to any third party.

5. Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
